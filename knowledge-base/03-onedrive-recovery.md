# Resume OneDrive sync and recover a file

Work OneDrive on Windows and in a browser | English menus

Check whether the local file is stale, overwritten or deleted before choosing a recovery action. Use the same work account and folder in the browser and on your computer.

## When the local copy is stale

1. Select the OneDrive cloud in the Windows notification area and check the account and status. View online opens the matching work OneDrive.
2. If syncing is paused, select Resume syncing in the activity panel or its settings menu.
3. Let synchronization finish. Close the local document tab and reopen the file from its actual OneDrive folder. Compare the full contents with the browser copy. A copy in Downloads is a separate file.

## When an existing file has the wrong contents

1. Before restoring, keep a separate copy of any current changes you still need. Close the file.
2. In OneDrive web, select the file and open More options > Version history. Inspect the earlier entry that should contain the needed work.
3. Open that entry menu and select Restore. Reopen the cloud file and the synchronized local file. Compare the complete contents with the expected version.

## When a file was deleted

1. In the same OneDrive web account, open Recycle bin. Find the item and confirm its original location.
2. Select that item and Restore. Return to the original folder, let sync finish and reopen both copies. Check the full contents.

## When to ask for help

If sync remains unhealthy, the needed version is absent or the item is missing from the recycle bin, report the account, folder, file name, time and exact message to support. Avoid overwriting a usable copy while the cause is unclear.

Synchronization also carries deletions between connected locations. History and the recycle bin provide recovery within their available limits; successful sync alone does not establish independent backup coverage.
