# OneDrive synchronisieren und Dateien wiederherstellen

Geschäftliches OneDrive unter Windows und im Browser | Englische Menünamen

Prüfen Sie zuerst, ob die lokale Datei veraltet, überschrieben oder gelöscht ist. Verwenden Sie im Browser und auf dem Computer dasselbe Geschäftskonto und denselben Ordner.

## Wenn die lokale Kopie veraltet ist

1. Wählen Sie das OneDrive Wolkensymbol im Windows Infobereich. Prüfen Sie Konto und Status. Über View online öffnen Sie das zugehörige geschäftliche OneDrive.
2. Falls die Synchronisierung angehalten wurde, wählen Sie Resume syncing im Aktivitätsfenster oder dessen Einstellungsmenü.
3. Warten Sie auf die Synchronisierung. Schließen Sie die lokale Dokumentregisterkarte und öffnen Sie die Datei erneut aus dem tatsächlichen OneDrive Ordner. Vergleichen Sie den gesamten Inhalt mit der Browserkopie. Eine Kopie in Downloads ist eine separate Datei.

## Wenn eine vorhandene Datei den falschen Inhalt hat

1. Sichern Sie vor der Wiederherstellung benötigte aktuelle Änderungen in einer separaten Kopie. Schließen Sie die Datei.
2. Markieren Sie die Datei in OneDrive im Browser. Öffnen Sie More options > Version history und prüfen Sie den früheren Eintrag mit dem benötigten Inhalt.
3. Wählen Sie im Menü dieses Eintrags Restore. Öffnen Sie danach die Clouddatei und die synchronisierte lokale Datei erneut. Vergleichen Sie den vollständigen Inhalt mit der erwarteten Version.

## Wenn eine Datei gelöscht wurde

1. Öffnen Sie im selben OneDrive Webkonto Recycle bin. Suchen Sie das Element und prüfen Sie seinen ursprünglichen Speicherort.
2. Markieren Sie dieses Element und wählen Sie Restore. Wechseln Sie zum ursprünglichen Ordner. Warten Sie auf die Synchronisierung, öffnen Sie beide Kopien erneut und prüfen Sie den vollständigen Inhalt.

## Wann Sie Unterstützung benötigen

Bleibt die Synchronisierung gestört oder fehlt die benötigte Version beziehungsweise das gelöschte Element, melden Sie Konto, Ordner, Dateiname, Zeitpunkt und genaue Fehlermeldung an den Support. Überschreiben Sie keine brauchbare Kopie, solange die Ursache unklar ist.

Die Synchronisierung überträgt auch Löschungen zwischen verbundenen Speicherorten. Versionsverlauf und Papierkorb ermöglichen eine Wiederherstellung innerhalb ihrer verfügbaren Grenzen. Ein erfolgreicher Abgleich allein belegt keine unabhängige Datensicherung.
