# Stage 03 — Exchange recipients, aliases and distribution

Status: PLANNED  
Target days: 4–5  
Execution date: not recorded

## Learning objective

Understand recipient types and verify actual mail delivery.

## Before starting

Confirm the required service entitlement, task-appropriate role, affected synthetic identities and recovery path. Record the actual tenant/client context privately. Earlier stages provide the baseline; unresolved prerequisites remain BLOCKED rather than assumed successful.

## Planned exercises

1. Compare user mailboxes, shared mailboxes, aliases, distribution lists and Microsoft 365 groups.
2. Create a Finance alias and a lab distribution list with explicit owners and members.
3. Send uniquely marked synthetic messages and record sender, recipient and time.
4. Change list membership and repeat delivery checks after propagation.

## Training case

A new Finance employee does not receive mail sent to the department address.

This is a planned lab scenario. No incident, root cause or repair outcome has been observed yet.

## Exit checks

- [ ] Mail to the alias arrives in the intended mailbox.
- [ ] Approved distribution-list members receive the marked message.
- [ ] An excluded account does not receive a distribution copy.
