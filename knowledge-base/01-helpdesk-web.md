# Use the Helpdesk shared mailbox

Outlook on the web | English menus

Open Helpdesk through your own work account and check the sender before sending. In this lab, Piotr has mailbox access and Send As permission for BFL-M365-Helpdesk.

## Open Helpdesk

1. Sign in to Outlook on the web with your own account. For the lab, use Piotr.
2. Select your profile picture or initials, then Open another mailbox.
3. Find BFL-M365-Helpdesk by its name or full work email address and select Open. In the new mailbox window, check that you are viewing Helpdesk folders.

## Send and check a reply

1. Choose New mail. If From is hidden, use More actions > Show From in the message toolbar.
2. Check that From contains the Helpdesk address. Select it, or enter the shared address if needed. Add the intended recipient, subject and message.
3. Send the message. Ask the recipient to check that the sender is Helpdesk, then reply.
4. Read the reply in the Helpdesk Inbox. Check From again when replying to an existing message.

## If something does not work

Mailbox access and sender permission are separate. Being able to read Helpdesk does not prove you can send as Helpdesk. Anna has a different sender permission in this lab and can appear as sending on behalf of Helpdesk.

If access or sending is denied, give support the exact error, time, intended sender and mailbox name. Continue using your own account; support can check the required delegation.
