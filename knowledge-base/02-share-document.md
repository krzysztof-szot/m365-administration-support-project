# Share a document with selected people

SharePoint and work OneDrive in a browser | English menus

Choose the intended recipients and the permission they need. Site or group access can remain after a sharing link is removed.

## Create a scoped link

1. Open the library or work OneDrive and select a file you are authorised to share. In the lab, Anna uses LAB-D08-KB-01 in Knowledge.
2. Select Share and open link settings. Choose People you choose or Specific people, depending on the interface.
3. Choose Can view for reading or Can edit when editing is intended. Apply the settings.
4. Add the intended person and check the resolved identity. In the lab, choose Piotr with Can view. Copy the configured link and give it to that person through your agreed channel.
5. Ask the recipient to open it with the intended work account and check the required result.

## Remove the selected link

1. As the file owner, select the file and open Manage access from Details or the sharing dialog.
2. Find the particular link you created. Remove that link and confirm the selected action. Keep other grants unless their removal is also intended.
3. Ask the recipient to reopen the saved old link. Separately check whether the document still opens through the library.

## Understand remaining access

Deleting one link does not establish that all access has ended. Piotr also has Read access to the Knowledge site in this lab and can still open KB-01 through its library. A Can view link also does not reduce an existing Can edit grant.

If all access must end, ask the site owner to review every relevant grant. If sharing options differ or are unavailable, ask the owner to confirm the intended route before broadening the audience.
